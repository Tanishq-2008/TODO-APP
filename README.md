## ✨ Features

- **Add & Organize:** Quickly create tasks with titles, descriptions, and due dates.
- **Interactive Checklists:** Check off completed tasks with satisfying animations.
- **Persistent Storage:** Your tasks are safely saved using Local Storage.
- **Dark/Light Mode:** Seamlessly switch between themes to match your system preferences.
- **Responsive Design:** Fully optimized for both desktop and mobile devices.
